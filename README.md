# 윤다형 | Backend Developer

2019년 7월부터 백엔드 개발을 해왔습니다. Java/Spring으로 포인트샵의 주문·결제·정산과 구독 서비스의 API·배치를 개발하고 운영했습니다.

## 해온 일

- **포인트샵:** 기존 Servlet/JDBC 코드를 분석하고 Spring을 단계적으로 도입한 뒤, 재구축 과정에서 회원·인증 기능과 데이터 이관을 맡았습니다. 복합 결제 취소, 결제 검증, 정산 로직도 개발·운영했습니다.
- **구독 서비스:** API **838개**를 목록화해 미사용 기능을 정리하고, 공통 모듈 의존성을 제거해 로컬 빌드 환경을 복구했습니다. 회원 대사 배치를 정리하고 Jenkins 파이프라인으로 이관했습니다.
- **오프라인 쿠폰 발급 API:** 인덱스와 DB 잠금 방식을 개선했습니다. **개발계 부하 테스트 기준** 응답 시간 **3,000ms → 8ms**, 처리량 **1.5 → 300 RPS**입니다. 운영 환경의 수치로 환산한 결과는 아닙니다.

## 사용해 온 기술

Java · Spring / Spring Boot · Spring Batch · MariaDB · MyBatis · Jenkins
